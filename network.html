1. OSI Model - ස්ථර 7 (අනිවාර්ය!)

7 Layers
1
L7 Application
User ට පේන තැන - HTTP, DNS, FTP, Email
Browser, Gmail
2
L6 Presentation
Data පරිවර්තනය - Encryption, Compression
SSL, JPEG
3
L5 Session
Connection එක පවත්වාගෙන යනවා
4
L4 Transport
TCP / UDP - විශ්වාසවන්තද / වේගවත්ද
Port Number තීරණය වෙනවා
5
L3 Network
IP - Router - ගමන හොයනවා
IP Address (192.168.1.1)
6
L2 Data Link
Switch, MAC Address
MAC: AA:BB:CC:DD:EE:FF
7
L1 Physical
Wire, Cable, Signal

10
8

12
Gateway: 192.168.1.1

13
DHCP

14
Static vs Dynamic
Static=අතින් දානවා, Dynamic=auto වෙනස් වෙනවා

4. TCP vs UDP / DNS

8
24

3-way handshake, නැතිවුණොත් ආපහු යවනවා

33
