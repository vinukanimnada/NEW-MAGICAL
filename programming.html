PART 5: Networking - Internet වැඩ කරන හැටි + Code

Python එකෙන් Network බලන හැටි

1
IP Address එක බලන හැටි - Python වලින්
import socket # ඔයාගේ Computer එකේ IP එක hostname = socket.gethostname() ip = socket.gethostbyname(hostname) print(f"ඔයාගේ IP: {ip}") # Google එකේ IP එක (DNS) google_ip = socket.gethostbyname("google.com") print(f"Google IP: {google_ip}")
2
Website එකක් වැඩ කරනවද බලන්න - Ping Tool එකක්
import requests websites = ["https://google.com", "https://facebook.com", "https://youtube.com"] for site in websites: try: r = requests.get(site, timeout=3) if r.status_code == 200: print(f"✅ {site} - වැඩ!") else: print(f"⚠️ {site} - {r.status_code}") except: print(f"❌ {site} - වැඩ නෑ")
📦 මේකට `pip install requests` කරන්න ඕන
3
Port Scanner - Mini Hacker Tool 😎
import socket target = "127.0.0.1" # ඔයාගේම PC එක print(f"Scanning {target}...") for port in [22, 80, 443, 3306, 8080]: s = socket.socket() s.settimeout(1) result = s.connect_ex((target, port)) if result == 0: print(f"🟢 Port {port} - Open") else: print(f"🔴 Port {port} - Closed") s.close()
